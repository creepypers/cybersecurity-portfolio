# 04 — Automatisation & Administration Système

## Objectif du module
Développer des automatisations sécurité et renforcer les pratiques d’administration Linux orientées défense.

## Sous-dossiers
- `scripts-python/` : scripts de détection, parsing, contrôle de configuration
- `hardening-linux/` : checklists et actions de durcissement système
- `outils-bash/` : commandes et scripts Bash pour opérations sécurité

## Scénarios cibles
1. Script Python de contrôle d’hygiène sécurité (permissions, services, ports)
2. Baseline de durcissement Linux (comptes, SSH, journalisation)
3. Outils Bash pour collecte rapide d’artefacts système

## Livrables attendus
- Scripts documentés et testables
- Guide de hardening reproductible
- Journal d’exécution avec résultats attendus

## Critères de validation
- Exécution sans erreurs sur environnement de test
- Sortie exploitable pour décision sécurité
- Respect des principes de moindre privilège
